Attack Map

What Happened
Entities and how they are linked, laid out in kill-chain order, with a phase-by-phase account underneath. An edge means two entities were named by the same event — co-occurrence, not causation — and the kill-chain lane is declared interpretation, not a verdict. Hover a node for the evidence behind it; click one to see only its events on the timeline.

Timeline

Cross-Source Chronology
The notable events of every loaded source, on one chronological axis. "Why" is the reason a row earned its place here — an ATT&CK technique, a high/critical Sigma hit, a high-signal event type such as log clearing or persistence installation, a THOR finding, or a failed action — it is a selection criterion, never a severity or a ranking; this list does not assert one, and the axis stays strictly temporal. When a dataset has nothing notable, the plain chronological head of events is shown instead ("context"), so the view is never mysteriously empty. Capped at 500 events.

Cases

Persistent Analyses
A case is a persistent analysis — the data itself, not just the conclusions — stored locally under analysis/cases/, which is why it can be reopened, annotated and compared later. It holds real client data: it never leaves this machine and is never committed.
No evidence to hand? Load Demo Case generates a complete simulated intrusion — ten source files across appliance logs, identity, EVTX, registry, scanners and a capture — and loads it as the case demo. Nothing in it is real, so it is safe to show anyone. It is rebuilt from scratch on each click.
Load one source at a time adds the same evidence in the order the story happened, one source per click: the point of the exercise is watching a bridge appear at the moment a second tool names the same thing, which the finished picture cannot show you.
Every analysis is saved into a case by default, because the correlation worth having happens between uploads: a capture today and an EVTX tomorrow only bridge if both are in the same store. A new case is created automatically the first time and named in the sidebar; switch or start another one here.
