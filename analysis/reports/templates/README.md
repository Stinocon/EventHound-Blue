# Deliverable templates

**Impersonal** templates (placeholder `{{...}}`, no real data) for recurring analysis deliverables. See §17 of `method/conventions.md`.

Usage: copy the template to `analysis/reports/`, rename with the date (e.g. `incident-2026-06-16.md`), populate placeholders from evidence. **Anonymize** (§9) any real data: the populated deliverable must not be committed (it belongs in `data/` or a private area). Do not modify the original template.

Available templates:
- `interpretazione-detection.template.md` — single detection interpretation.
- `analisi-incidente.template.md` — incident reconstruction with timeline.

Create a new template only when the same document type is produced ≥ 2 times.
